# Screenshots

Actual screenshots are intentionally not pre-populated: package installation and the Next.js server were not available during generation. After running `npm install && npm run dev`, use:

```bash
CHROMIUM_PATH=/usr/bin/chromium python scripts/capture.py
```

All images here must be captured from the running routes (not synthetic composites). Expected filenames and viewport sizes are listed in `docs/demo-script.md`.
